# 촬영 사진을 제외한 단일 통합 실험 결과

실행일: 2026-11-05. 사용자가 직접 촬영 사진 없이 진행하도록 지시하여 프로토콜 3.0으로 변경했다. 아래는 실제 실행 결과다.

**주 결과: 새로운 MathWriting 실제 손글씨 수식 317개 중 1개 전체 일치, 0.32%.**
정규화 토큰 편집 거리 0.6494, 문법 오류율 4.10%. 95% 층화 bootstrap 구간: 0.00%~0.95%.

**현재 모델은 실제 수식 인식 도구로 사용하기에 정확도가 부족하다.** 실험 절차의 수행 완료와 실용성 목표 달성을 구분한다.

## 하나의 실행과 선택

- 실제 수식 학습 3872, 검증 363, 새 시험 317; 학습 보조 합성 2,000장.
- 보조 기호 50,424개 사용. 가장 적은 클래스의 원본 27개. 클래스 최소 50개 수집 조건은 직접 촬영 제외에 따라 가용 자료 사용으로 변경하고 한계를 기록했다.
- CNN 초기화 10에포크 후 같은 CNN–BiLSTM–LSTM을 공동 학습했다. 본학습 26에포크, 에포크당 600회, 실제 7장+합성 3장 배치.
- 검증으로 선택한 에포크 18, 검증 전체 일치율 2.20%. 시험은 선택에 사용하지 않았다.
- NVIDIA GeForce RTX 3050 Ti Laptop GPU, PyTorch 2.7.1+cu128, 파라미터 699,285개.
- 전체 이미지의 원본/약한 증강 2개 분할 결과를 캐시했다. 캐시는 픽셀 crop과 위치이며 CNN 확률/특징을 detach해서 저장한 것이 아니다. 이후 매 학습마다 CNN 재계산과 약한 기호 증강을 수행했다.
- 연결 성분/기하 병합은 고정, CNN과 LSTM의 연결은 역전파로 학습했다.
- 자동 crop은 경계 상자 내부의 전경을 포함하므로 이웃 획이 섞일 수 있다. 원본 기호/합성 재료는 정답 획 기반으로 준비했다.

## 데이터 검증과 범위

- 원본 전체 253,182개를 검사했고 과거 사용한 MathWriting 시험 ID 800개를 제외했다. 수식 내용과 이미지 해시의 집합 간 중복은 0이다.
- MathWriting 기호 6423개 중 6183개의 부모를 원래 획으로 연결했다. 미연결 또는 검증·시험 내용과 연결될 수 있는 보조 기호 58개를 보수적으로 제외하고 합성에도 사용하지 않았다.
- 클래스는 영문 대소문자·숫자·기본 연산자·소수점 70종. 사진은 사용하지 않았고 사진 정확도나 새 필자 일반화를 측정했다고 주장하지 않는다.
- 데이터 수량 변경과 사진 제외는 본학습·시험 전에 확정했다. 동일 시험 결과로 모델을 다시 고르지 않았다.

## 실행 방법

이 폴더에서 상위 프로젝트 Python 환경을 사용한다.

```powershell
../.venv/Scripts/python.exe run_digital.py
../.venv/Scripts/python.exe finalize_digital.py
../.venv/Scripts/python.exe recognize.py data/images/이미지.png
../.venv/Scripts/python.exe web.py --port 8768
```

run_digital.py는 동일한 데이터/코드 해시에서만 마지막 에포크를 재개한다. 주 결과와 전체 예측은 mathwriting_test.json 및 test_gallery.html에 있다. UI/API 검증 기록은 ui_checks.json에 별도로 저장한다.

## 해석

검증 성능에 비해 학습 손실이 낮아지는 양상이 있어 새로운 수식 내용에 대한 일반화가 부족하다. 이는 손글씨 전체 수식 자료로 학습했음에도 단순 CNN 확률·좌표와 고정 길이 인코더 상태만으로 충분한 인식 성능을 얻지 못한 결과다. 단일 실행이므로 특정 구성 하나의 인과적 효과나 다른 알고리즘 대비 우월성을 주장하지 않는다. 새 모델을 개선하려면 이번 시험과 분리된 새 시험을 준비해야 한다.

## 학습 자료 재인식 사후 진단

고정한 같은 모델에 실제 학습 수식 중 유형별 25개씩 총 100개를 시드42로 추출하여 자유 생성했다. 전체 일치율은 56.00%였다. 이는 학습 자료를 다시 본 사후 진단이며 독립 시험이나 모델 선택 지표가 아니다.
학습 자료 재인식 56.00%와 검증 2.20%, 새로운 시험 0.32%의 큰 차이는 새 수식 내용에 대한 일반화 부족과 과적합 양상을 보여준다.
