# 통합 실험 활성 프로토콜 3.0

사용자 지시: 직접 촬영 사진은 없이 진행한다. 사진 수집·검증·시험 조건을 제거하고 MathWriting 실제 손글씨 수식을 주 평가로 사용한다.

- 실제 수식: 학습 3,872, 검증 363, 시험 317. 합성은 학습 보조 2,000장.
- 단일 CNN 70종 → 78차원 확률/기하 입력 → 양방향 LSTM → LSTM 디코더 79토큰.
- 초기 CNN 10에포크, 본학습 최대 60, 에포크당 600회 갱신. 실제 7장+합성 3장. 시드 42.
- 주 선택 지표는 MathWriting 검증 전체 일치율, 동률이면 토큰 편집 거리. 사진 점수는 사용하지 않는다.
- 직접 수집 없이 가용 기호를 균형 추출한다. 실제 허용 기호 50,424개, 가장 작은 클래스 27개이며 클래스별 한계를 공개한다.
- 증강된 전체 이미지 두 뷰의 픽셀 crop/기하를 캐시하며 CNN 확률은 매번 재계산하여 공동 역전파한다.
- 시험은 선택에 사용하지 않는다. 고정 모델에 대한 CROHME 영역 진단과 새 내용의 합성 분수 30쌍 진단을 부가한다. 서로 다른 자료의 점수를 합산하지 않는다.
- 사진 인식 성능과 필자 독립 성능을 주장하지 않는다. 브라우저 실클릭 검증 범위는 ui_checks.json에 명시한다.

실제 실행과 결과: [REPORT.md](REPORT.md). 수치 설정: protocol.json. 과거 사진 포함 설계: PROTOCOL_V2_1_HISTORY.md. 현재 주 실행 명령은 상위 프로젝트 Python으로 run_experiment.py를 실행하는 것이다. 완료된 실험을 재실행하면 고정 결과를 보존한다.
